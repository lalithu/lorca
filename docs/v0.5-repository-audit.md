# v0.5 repository audit — complete tracked-file inventory

Baseline: `v0.4.0-nominal.1` (`0d3f78166a10fb7f624933fe4144326f4dce9ba7`).

## Scope and method

GitHub's recursive tree returned **259 entries**: **228 files** and **31 directory entries** (not truncated). All **223** UTF-8/text paths were fetched and scanned, including docs, manifests, Rust, Swift, Python, and tests. The **5** binary assets were inventoried by path and size, not decoded or visually inspected. High-impact runtime/context/storage/provider/tool/UI/test files received a deeper structural and control-flow inspection. This is a source audit, **not** a successful build, test run, or claim that every algorithm in ancillary files has been manually line-reviewed.

## Cross-cutting findings

1. **Correct core loop already exists.** `agentloop/execution.rs` implements model-selected native tools, Rust authorization, actual observations and model-selected final answer; `Registry` exposes schemas adaptively.
2. **The current memory store is a chat transcript, not an independently indexed archive.** `storage.rs` serializes version-1 conversation JSON and nested `agentHistory`; `Context` compacts a separate model-facing projection.
3. **Oversized input is currently rejected before context-fitting.** `agentloop/runtime.rs` has an 8K-byte task gate, and `core/agent_chats.rs` also limits linked continuation text; this must move to an ingestion/manifest boundary.
4. **Output exhaustion has bounded one-step recovery.** Provider adapters expose generation stop/length signals; a segmented-output ledger must be added without running truncated tool JSON.
5. **Rust completion verification is mostly informational in the nominal release.** Semantic `Requirements`/inspection machinery should be decoupled from execution permissions in a later, separately tested cleanup; permission protection remains.
6. **The native UI is a presentation client.** Chat model, activity stream, context bar, conversation menu, and copy functionality are available for small extensions without a new Swift agent runtime.
7. **Job Apps must remain isolated.** `job_session.rs` instantiates a custom restricted tool registry; additional normal-chat recall tools must not implicitly appear there.
8. **The current model preparation remains lazy and provider-owned.** Hardware-specific model recommendation/allocation belongs to the final milestone.
